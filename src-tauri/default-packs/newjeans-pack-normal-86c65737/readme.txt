My Custom Cursor 8
==================

Author: josuegrotesco

This animated cursor includes 3 files with multiple sizes.
Some files contain multiple sizes for automatic Windows DPI scaling.
Choose the file that best fits your display.

Files included:
  - NewJeans pack - My Custom Cursor 8_32-48-64.ani
  - NewJeans pack - My Custom Cursor 8_72-96-128.ani
  - NewJeans pack - My Custom Cursor 8_256.ani

Installation:
  1. Copy the cursor file to a folder (e.g., C:\Windows\Cursors\)
  2. Open Control Panel > Mouse > Pointers
  3. Click 'Browse' to select the cursor file
